# Globemoji

The releases of Globemoji, an emoji picker for macOS 26 or later on Apple silicon. This
repository holds only the finished app; the source is private.

To install: download `Globemoji-<version>.zip` from the newest release, open it, drag
**Globemoji** into **Applications**, and open it from there. macOS will say it can't check the
app: open **System Settings › Privacy & Security**, scroll down, click **Open Anyway** next to
Globemoji, and open it again. Then allow Accessibility when Globemoji asks.

After that, Globemoji keeps itself up to date: it checks once a day and installs a new version
when your Mac's screen turns off or it restarts.
